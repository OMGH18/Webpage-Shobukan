# Badges officiels des stores

- `app-store-en.svg`, `google-play-en.svg` : badges officiels Apple et Google (anglais).
- Pour les versions françaises, déposer ici `app-store-fr.svg` et `google-play-fr.svg`
  (téléchargés depuis https://developer.apple.com/fr/app-store/marketing/guidelines/
  et https://play.google.com/intl/fr/badges/) : le site les utilisera
  automatiquement sur les pages françaises, sans autre modification.

Ne pas modifier le dessin des badges (règles Apple et Google).
