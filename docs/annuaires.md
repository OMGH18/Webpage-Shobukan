# Annuaires et fiches : kit d'inscription Shobukan

Objectif : que Shobukan existe, avec **exactement la même description**, sur les
sites que Google et les assistants IA consultent pour répondre à « un jeu de
soirée manga », « un Undercover anime » ou « une alternative à Kahoot entre
amis ». Chaque fiche apporte aussi un lien durable vers le site.

Règle d'or : **mêmes nom, phrase d'accroche, liens et chiffres partout**. Les IA
recoupent les sources : une info cohérente sur 6 sites pèse plus qu'une info
différente sur 15.

## 2. Où inscrire Shobukan (par ordre de priorité)

Les sites en **anglais** utilisent la description EN, les sites français la FR.
« Lien » = ce qu'apporte la fiche pour le référencement.

### Priorité 1 — cette semaine

| # | Site | Pourquoi | Comment |
|---|---|---|---|
| 1 | **IGDB** (igdb.com) | La base de jeux de Twitch. Elle est reprise automatiquement par Twitch, Backloggd et beaucoup d'apps de suivi de jeux : une fiche ici en crée plusieurs. Source fréquente des IA pour les jeux vidéo. | Se connecter avec un compte **Twitch**, puis *Games → Add Game*. Plateformes : iOS, Android. Genres : Quiz/Trivia, Party. Entreprise : Djabel Solutions (développeur **et** éditeur). Ajouter tous les liens du tableau. Description EN de 1 ou 2 paragraphes (pas plus, c'est leur règle). Validation sous ~24 h. |
| 2 | **AlternativeTo** (alternativeto.net) | Les IA et Google s'en servent pour répondre à « une alternative à Kahoot / Heads Up / Spyfall ». | Créer un compte, proposer une nouvelle application, puis la déclarer comme alternative aux apps de la liste « Alternative à ». Licence : Freemium. Plateformes : iPhone, Android. |
| 3 | **MobyGames** (mobygames.com) | Base de jeux historique et très crédible. | Compte gratuit, puis contribuer une fiche de jeu (plateformes iPhone et Android). Leur relecture est stricte et parfois lente : remplir précisément (date de sortie, éditeur, développeur). |

mieux, et les pénalise au pire.

## 3. Instructions pour l'agent ChatGPT

À copier-coller dans ChatGPT (mode Agent), en même temps que ce document.

```text
Tu vas inscrire mon jeu mobile Shobukan sur des annuaires en ligne, dans mon navigateur.
Toutes les informations à saisir sont dans le document « Annuaires et fiches : kit d'inscription Shobukan » que je te fournis : utilise EXACTEMENT ces textes et ces liens, sans les réécrire ni inventer d'information (pas de nombre de téléchargements, pas de récompense, pas d'avis).

RÈGLES DE SÉCURITÉ
- Création de compte ou connexion (Twitch, Discord, e-mail…) : rends-moi la main, je le fais moi-même, y compris les mots de passe, captchas et double authentification.
- N'accepte aucune option payante, aucun abonnement, aucune mise en avant sponsorisée.
- N'accepte pas d'e-mails marketing quand une case est proposée.
- Si un site demande un fichier (icône, captures d'écran), demande-le-moi.
- Si une information demandée n'est pas dans le document, laisse le champ vide ou demande-moi.
- Description en anglais sur les sites en anglais, en français sur les sites français.
- Pour le lien Google Play, utilise le modèle avec utm_source égal au nom du site (ex. igdb, alternativeto).

ORDRE
1. IGDB (igdb.com) : Games > Add Game.
2. AlternativeTo (alternativeto.net) : ajouter l'application, puis la lier comme alternative aux apps listées dans le document.
3. MobyGames (mobygames.com) : contribuer une fiche de jeu.
4. Disboard (disboard.org) : lister le serveur Discord (je devrai peut-être inviter le bot moi-même).
Arrête-toi après ces 4 sites et fais-moi un compte rendu.

COMPTE RENDU
Pour chaque site : statut (publié / en attente de validation / refusé / bloqué), adresse de la fiche si elle existe, et tout message d'erreur ou demande du site.
```
